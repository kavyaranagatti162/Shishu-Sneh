Shishu Sneh

Shishu Sneh is a child care and support application developed to help parents and caregivers manage children’s information in a simple and organized way. The project focuses on maintaining essential child-related records, improving communication, and providing an easy-to-use digital platform for better child care management.

Features
User-friendly interface
Child information management
Health and activity tracking
Organized record maintenance
Responsive and simple design
Technologies Used
Android Studio
Java/XML
Firebase / SQLite (if used)
Purpose

The main objective of this project is to provide a smart and efficient solution for managing child care details digitally, making information easily accessible and well organized.
